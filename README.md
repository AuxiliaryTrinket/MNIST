# MNIST

# Определение числа на изображении

## О проекте

Проект посвящён решению задачи многоклассовой классификации — распознаванию рукописных цифр на изображениях. В качестве объекта предсказания выступает изображение, а класс — это цифра от 0 до 9, изображённая на нём.

Задача относится к области компьютерного зрения и решается с помощью методов машинного обучения.

## Цель проекта

Построить модель, которая по значениям пикселей изображения способна точно предсказывать, какая цифра на нём изображена.

## Данные

Используется подмножество классического набора MNIST — стандартного бенчмарка для задач распознавания рукописных цифр.

- Объём выборки: 42 000 изображений
- Разрешение: 28×28 пикселей (чёрно-белые)
- Классы: цифры от 0 до 9 (10 классов)
- Формат: таблица `images.csv` (внутри zip-архива)

### Структура данных

Каждая строка таблицы — одно изображение:

| Колонка | Описание |
|---|---|
| `pixel0`, `pixel1`, …, `pixel783` | Значения интенсивности пикселей (от 0 до 255). 784 = 28×28 |
| `label` | Целевая переменная — какая цифра изображена (0–9) |

Интерпретация значений пикселей:
- 0 — абсолютно чёрный пиксель
- 255 — абсолютно белый пиксель
- Промежуточные значения — оттенки серого

### Целевая переменная

Необходимо по признакам `pixel0 … pixel783` предсказать значение `label`.

## Подход к решению

1. Загрузка и предобработка данных — чтение CSV, нормализация пикселей (приведение к диапазону 0–1), разделение на обучающую и тестовую выборки.
2. Визуализация — просмотр примеров изображений для понимания данных.
3. Построение моделей — от простых baseline-решений (логистическая регрессия) до нейронных сетей (MLP, CNN).
4. Оценка качества — метрики accuracy, confusion matrix, анализ ошибок модели.
5. Улучшение результата — подбор гиперпараметров, аугментация, регуляризация.

## Ожидаемые результаты

- Обученная модель, предсказывающая цифру по изображению
- Оценка качества модели на отложенной выборке
- Анализ типичных ошибок модели
- Выводы о применимости выбранного подхода

MNIST — база рукописных цифр, собранная Национальным институтом стандартов и технологий США. Широко используется как учебный датасет для задач компьютерного зрения.
